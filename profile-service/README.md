Stores and manages user expertise, skills, education, and experience details.
Utilizes Amazon DynamoDB for storing user profile details.

** Actions and Interactions **

Users can Create and Manage their profiles.
Users can Add and Update their Expertise, Skills, Education, and Experience details.
Users can Search for other Users based on expertise, skills, education, or experience.

OpenAPI: http://localhost:7070/swagger-ui/index.html
